
# Python Basic Calculator — Git & GitHub Workflow

## Overview

A beginner Python calculator developed as a hands-on project
to practise Git version control and GitHub collaboration.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero protection
- Invalid-operation handling

## Requirements

- Python 3
- Git
- A GitHub account

## Run the application

```bash
python3 calculator.py
```

## Git skills practised

- Repository management
- Staging and commits
- Feature branches
- Push and pull
- Pull requests and merging
- Merge conflict resolution
- Git history and release tags

## Planned improvements

- Floor division
- Modulus
- Better input validation
- Improved documentation

## Learning objective

Practise a realistic Git workflow while developing a simple
Python application using beginner-level programming concepts.
